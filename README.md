# 婚礼请柬网站 · 陶林伟 & 肖佩韦

一个单页静态婚礼请柬网站，包含婚礼信息展示和出席登记表单。

## 页面内容

- 婚礼请柬主视觉：`images/invitation.jpg`，一张完整设计好的请柬图片（标题、新人姓名、日期、
  农历日期、签到合影/晚宴仪式时间、婚礼地址等信息都画在图里）
- 请柬图下方是新人的婚纱照 `images/couple.jpg`
- 再下面是一条装饰性的走动动画（详见下方"走动动画"）
- 出席登记表单：姓名、是否出席、出席人数（下拉，最多 5 人）、所在城市（默认"上海"）、备注
- 页尾是新人姓名与日期

## 走动动画

页面中段有一条手绘线条风格的小动画，四个角色会以不同速度、不同时间间隔循环走过：

| 角色 | 特征画法 |
| --- | --- |
| 英短蓝白 | 圆耳朵、身上一条分色曲线 |
| 新郎 & 新娘 | 新郎西装领结、新娘长发婚纱捧花，两人牵手 |
| 金吉拉白 | 身体轮廓带绒毛凸起、大圆眼睛、蓬松羽状尾巴 |
| 美短 | 额头 M 纹、身上虎斑条纹、尾巴环纹 |

实现要点（都在 `index.html` 的 `<style>` 与内联 SVG 里）：

- **图形**：纯内联 SVG 路径，没有外部图片。头部/身体重叠处用白色填充（`.fw` 类）遮挡后面的线条，
  避免出现接缝
- **走路**：每条腿是一个 `.leg` 路径，用 CSS `transform-box:fill-box` + `transform-origin:50% 0`
  让它绕"胯部"来回旋转；`.leg.b` 用反相的关键帧，形成左右腿交替的连续步态
- **其他细节**：尾巴摆动（`.tail`）、婚纱裙摆轻晃（`.skirt`）、整体上下轻微起伏（`bob`）
- **无障碍**：系统开启"减少动态效果"时，整条动画会自动隐藏

想调整节奏，改每个 `.sprite` 上的 `--dur`（走完全程的时长）和 `--delay`（出场延迟）即可。

## 微信分享卡片

分享链接到微信时会显示一张卡片，包含标题、描述、缩略图三部分，这些都在
`index.html` 的 `<head>` 里配置好了：

- 标题、描述在 `<head>` 的 `og:title` / `og:description` 里，改文案直接改这几行
- 缩略图是那张手绘插画裁成的方图 `images/share.jpg`（400×400、约 40KB —— 图太大微信会直接跳过）
- 另外在 `<body>` 最前面藏了一张同样的图，因为有些抓取程序不读 meta，只取 HTML 里的第一张图

> **换域名后必须改**：`og:url`、`og:image`、`itemprop=image`、`link rel=image_src`、
> `twitter:image` 这几行写的是完整绝对地址。微信基本不认相对路径，域名变了就要一起更新。

需要知道的限制：微信对普通链接**并不保证**读取 og 标签，分享卡片是它自己的爬虫按
启发式规则生成的。想要完全控制标题/描述/图标，官方途径是接入微信 JS-SDK，
而那需要有公众号并配置 JS 安全域名。上面这些做法是把命中率拉满，但没法保证 100%。

微信抓取结果缓存较久。改完重新部署后卡片没更新的话，在网址后面加个参数
（比如 `?v=2`）换成一个"新链接"再分享，或者等缓存过期。

## 出席登记表单（存到 EdgeOne KV）

访客填完表单点"提交登记"后，请求发到 `/api/rsvp` 边缘函数，函数把记录写进
EdgeOne 自带的 KV 存储。**数据全程留在腾讯云内部**，不依赖任何第三方服务，
国内访客提交不用走跨境网络。

- **新增**：第一次用某个姓名提交，新建一条记录
- **修改**：之后用同样的姓名再提交一次，会覆盖那条记录（不会产生重复），
  首次登记时间会保留
- 人数超出 1–5 会被自动收进范围，姓名为空会被拒绝

> 用"姓名"作为唯一标识。万一两位宾客同名，后填的会覆盖先填的。
> 如果担心重名，告诉我，可以改成"姓名 + 手机号"一起作为标识。

### 一次性配置（两步）

1. **创建并绑定 KV 命名空间**
   - EdgeOne 控制台 → Pages → 你的项目 → 「KV 存储」，新建一个命名空间
   - 回到项目里把它绑定给函数，**变量名必须填 `RSVP_KV`**（代码里就是按这个名字取的）

2. **设置后台口令**
   - 项目 → 设置 → 环境变量，新增 `ADMIN_TOKEN`，值自己定一个密码
   - 这个值不要写进代码仓库

配置完重新部署一次即可生效。

### 查看名单

打开 `你的网址/admin.html`，输入 `ADMIN_TOKEN` 设的口令，就能看到：

- 登记条数 / 出席家庭数 / 出席总人数 三个统计
- 完整名单表格（姓名、是否出席、人数、城市、备注、登记时间）
- 「导出 Excel（CSV）」按钮，导出的文件带 UTF-8 BOM，Excel 打开中文不乱码

口令只在浏览器当前标签页里临时保存，关掉就没了。这个页面加了 `noindex`，
不会被搜索引擎收录，但**知道网址的人仍然可以访问到登录框**——口令别设得太简单。

## 本地预览

直接用浏览器打开 `index.html` 可以看到页面样式和动画，但登记表单需要 EdgeOne Pages
的边缘函数 + KV 环境才能跑通（本地静态打开无法调用 `/api/rsvp`）。

## 部署到 EdgeOne Pages（推荐：绑定 GitHub 自动部署）

1. 把本仓库推送到你自己的 GitHub 账号下（已完成，仓库地址见 GitHub 页面）。
2. 登录腾讯云 EdgeOne Pages 控制台，选择"创建项目" → 选择"导入 Git 仓库"，
   授权并选择这个 GitHub 仓库。
3. 构建配置：本项目是纯静态 HTML + Pages Functions，**不需要构建命令**，
   输出目录填根目录（`/` 或留空）即可；`functions/` 目录会被 EdgeOne 自动识别为边缘函数。
4. 按上面"一次性配置"绑定 KV 命名空间（`RSVP_KV`）并设置 `ADMIN_TOKEN`。
5. 绑定完成后，以后每次把改动 push 到 GitHub 的这个仓库，EdgeOne 会自动重新部署，
   不用再手动上传文件。

### 如果使用"直接上传"方式部署

需要把 `index.html`、`images/` 和 `functions/` 三者一起上传，且要确认 EdgeOne Pages
的"直接上传"方式支持部署 Pages Functions（不同上传方式对 Functions 的支持可能不同，
如果发现表单提交没反应，建议改用"绑定 GitHub 仓库"的方式部署）。
