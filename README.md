# 婚礼请柬网站 · 陶林伟 & 肖佩韦

一个单页静态婚礼请柬网站，包含婚礼信息展示和出席登记表单。

## 页面内容

- 婚礼请柬主视觉（新人姓名、日期、农历日期）
- 签到合影 / 晚宴仪式 时间安排
- 婚礼地址
- 出席登记表单：姓名、是否出席、出席人数、所在城市（默认"上海"）、备注

## 目录结构

```
.
├── index.html   # 网站唯一页面，样式与交互均内嵌在此文件中
└── README.md
```

本站不依赖任何外部图片或字体文件，`index.html` 单文件即可完整运行，
不用担心部署时漏传图片文件夹的问题。

## 出席登记表单说明

表单目前通过 **邮件（mailto）** 方式提交：访客点击"提交登记"后，
会跳转打开访客本机的邮件客户端，自动填好收件人、主题和登记内容，
访客确认发送后，登记信息就会以邮件形式发到新人邮箱。

- 当前收件邮箱写死在 `index.html` 底部 `<script>` 里的这一行：

  ```js
  window.location.href = 'mailto:dylan.tao94@gmail.com?subject=' + subject + '&body=' + body;
  ```

  如需修改收件邮箱，直接替换这里的地址即可。

- 这种方式的局限：依赖访客本机装有邮件客户端并完成登录，手机上部分浏览器
  可能无法自动跳转。如果后续想要更可靠的"填完直接存起来"的登记方式
  （比如存到表格、飞书/腾讯文档，或用第三方表单服务），可以再找我升级。

## 本地预览

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或启动服务器。

## 部署到 EdgeOne Pages（推荐：绑定 GitHub 自动部署）

1. 把本仓库推送到你自己的 GitHub 账号下（已完成，仓库地址见 GitHub 页面）。
2. 登录腾讯云 EdgeOne Pages 控制台，选择"创建项目" → 选择"导入 Git 仓库"，
   授权并选择这个 GitHub 仓库。
3. 构建配置：本项目是纯静态 HTML，**不需要构建命令**，输出目录填根目录（`/` 或留空）即可。
4. 绑定完成后，以后每次把改动 push 到 GitHub 的这个仓库，EdgeOne 会自动重新部署，
   不用再手动上传文件。

### 如果使用"直接上传"方式部署

把 `index.html` 直接拖到 EdgeOne Pages 的上传界面即可（本项目没有 `images` 等
子文件夹，不存在漏传文件夹导致图片 404 的问题）。

## 修改内容

婚礼信息（姓名、日期、地址、登记截止日期等）都是纯文本写在 `index.html` 里，
直接搜索对应文字修改即可；也可以把要改的内容发给我，由我代为修改后重新推送。
